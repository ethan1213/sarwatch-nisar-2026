# Uso de IA y fuentes

Asistentes de programación, incluidos Claude Code y Codex, ayudaron a programar, revisar, probar y documentar. La aplicación publicada no llama a APIs de modelos de lenguaje. El asistente explicativo usa herramientas locales, fuentes y un verificador; no genera las cifras científicas. Los resultados proceden de scripts y archivos JSON versionados.

Las revisiones automáticas no sustituyen evaluación científica externa ni pruebas de comprensión con personas.

- NISAR/ASF: https://nisar-docs.asf.alaska.edu/availability-overview/
- GOES NOAA: https://www.ospo.noaa.gov/Products/land/hms.html
- FIRMS NASA: https://firms.modaps.eosdis.nasa.gov/content/active_fire/
- Sentinel-2 / Planetary Computer: https://planetarycomputer.microsoft.com/dataset/sentinel-2-l2a
- Copernicus DEM: https://planetarycomputer.microsoft.com/dataset/cop-dem-glo-30
- WorldCover: https://planetarycomputer.microsoft.com/dataset/esa-worldcover
- Open-Meteo y ERA5: https://open-meteo.com/en/docs/historical-weather-api

La licencia Apache-2.0 cubre el código propio. Las fuentes tipográficas conservan sus licencias SIL OFL en web/public/fonts. Los datos y mapas conservan los términos y atribuciones de sus proveedores.
