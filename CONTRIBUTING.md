# Colaboración

Usar ramas `codex/descripcion` o las acordadas por el equipo. PR: problema, cambio, evidencia y límites. Ejecutar `python -m unittest discover -s tests -v`; cambios SAR requieren grilla, unidades, nodata y procedencia comprobados.

No subir credenciales, contactos privados ni HDF5. No presentar datos sintéticos como observaciones. Revisar atribución/licencia de fuentes. La licencia del proyecto y publicación abierta se decidirán antes de enviar al desafío.
